# נגיצ'ק

אפליקציית MVP מקומית בדפדפן, המבוססת על ה-SRD המצורף.

גרסת אפליקציה נוכחית: `1.13.1`

מה כלול:

- שער ביקורת מלא: נתוני היתר ומבנה, ייעוד, קיבולת, חייב בנגישות, מסמכים, פטורים והיקף בדיקה
- צ'קליסטים מפורקים למבנה, שירות ודיגיטל עם מקורות ויעדי מדידה
- מאגר דרישות מקומי: מקור, סעיף, מהדורה, ערך נדרש וחריגים עבור פריטי ליבה, עם סימון מפורש לדרישות אימות
- סימון תקין / ליקוי / לא רלוונטי
- תיק ליקוי מקצועי: ממצא, דרישה, המלצה, מדידה, כלי, נקודה, תחולה, קבוצות מושפעות ואחריות לתיקון
- שלוש ראיות לכל ליקוי (הקשר, אלמנט, פרט/מדידה), GPS ברמת ליקוי ומזהה אלמנט להיסטוריה מקומית
- ביקורת חוזרת: מדידה חוזרת, שם מאמת, ראיית אחרי וסגירה רק לאחר אימות בשטח
- צ'קליסט מלון מפורט: חדרים נגישים, חדר רחצה, קבלה, שטחים ציבוריים, פנאי, מידע וחירום
- קטלוגים ענפיים נוספים: בית ספר וגן ילדים, מקום תפילה, קהילה, ספרייה, תרבות, ספורט, פארק, חוף, בית עלמין, רשות, מסחר ובנק
- צירוף מקומי של היתר, פטור, התאמה חלופית ודוח קודם; מסמכים וראיות נכללים בגיבוי המקומי
- לוח בקרה, Audit בסיסי, סטטוס `PENDING_AI`
- BYOK אופציונלי: מפתח נשמר ב-`sessionStorage` בלבד ואינו נכנס לייצוא או ל-`localStorage`
- ניתוח תמונות דרך OpenAI Responses API בלחיצה יזומה בלבד, עם תוצאה מובנית שממתינה לאישור אנושי
- תצפית AI מפורטת בעברית, פעולה מוצעת, מגבלות, ודאות וכפתורי אישור או דחייה אנושיים
- בסיס נורמטיבי מוצע לכל ניתוח AI, מוגבל למקורות המותרים בצ׳קליסט ודורש אימות תחולה מקצועי
- קטלוג ביקורות מורחב למתו"ס, נגישות השירות, דיגיטל, נגישות ייעודית ואתרי החובה ב-FR-2.1
- דוח תיקונים לביקורת: פעולות, עדיפות, טקסט להורדה והדפסה או שמירה כ-PDF
- תיבת דרישה נורמטיבית בכל דיווח ליקוי: חוק/תקנה/תקן מוצעים ומה צריך להיות בפועל
- נתוני הדגמה למבנה ציבורי ולמרכז שירות נגיש
- יעדי מדידה מוצגים בדוח ובתוצאת AI כאשר קיים סף מאומת בפריט הבדיקה
- רכיב התאמות נגישות: דילוג לתוכן, מקלדת, גודל טקסט, ניגודיות והדגשת קישורים
- מסך "מקורות מידע" עם ביבליוגרפיה, מעמד נורמטיבי, סטטוס אימות וקישורים למקורות הנתונים של האפליקציה
- מסלולי תחולה לבניין קיים או חדש, מגורים חדשים, מקום שאינו בניין, שירות, דיגיטל ושירות ייעודי
- הצהרת נגישות פנימית, לצד התאמות מקלדת, דילוג לתוכן, ניגודיות, גודל טקסט והדגשת קישורים
- שפת ממשק אחידה ונגישה, עם פריסה סלולרית קומפקטית לעבודה בשטח
- שמירת נתונים ותמונות ב-IndexedDB מקומי, עם העברה אוטומטית מהשמירה הקודמת
- GPS לפי אישור מפורש של המשתמש בעת פתיחת ביקורת
- לוח בקרה פעיל: לחיצה על חומרה מסננת ישירות את הליקויים, ולחיצה על ביקורת אחרונה פותחת אותה
- חיפוש וסינון ליקויים לפי אתר, כתובת, אלמנט, מזהה, אחראי, איחור וביקורת חוזרת
- פעולות שדה מהירות: פתיחת מצלמה לצירוף ראיה והעתקת מזהה ליקוי
- הגנת נתוני שטח: בקשת אחסון קבוע, הצגת נפח, דחיסת תמונות מקומית וגיבוי מלא או קל ללא מדיה
- ייבוא גיבוי בטוח: בחירה מפורשת בין החלפת כל הנתונים לבין מיזוג ללא דריסת מזהים מקומיים
- סיום סקר מתועד, השוואה לביקורת קודמת באותה כתובת ותיעוד הדרכת נגישות
- כפתורי מידע נגישים בלחיצה לבחירות מקצועיות ולפעולות רגישות; נסגרים בלחיצה חוזרת, מחוץ להסבר או ב-`Esc`
- צ'קליסטי מרחב ציבורי: מדרכה ודרך נגישה, מעבר חציה וצומת, וכביש/שפת מדרכה עם ערכי סף מסומנים לאימות תחולה
- צ'קליסטים נפרדים למרחב מוגן ומקלט ולנגישות חושית במרחב הציבורי, לרבות מידע חזותי וקולי, הכוונה, התרעה וסיוע
- תמצית מדידה אחידה בליקוי ובדוחות: ערך נמדד, ערך נדרש, מקור וסעיף, מהדורה, תחולה, חריגים ופער לתיקון כאשר ניתן לחשבו בבטחה
- גיבוי וייבוא ידניים ב-JSON בין מכשירים, לצד ייצוא CSV

כדי להריץ:

1. פתחו את `index.html` בדפדפן.
2. אפשר ללחוץ על "טען נתוני הדגמה" כדי לראות זרימה מלאה.

## התקנה בטלפון (PWA)

הקבצים כוללים Manifest ו-Service Worker, כך שהאפליקציה יכולה לפעול כ-PWA ולהיטען גם ללא רשת לאחר הפתיחה הראשונה.

1. פרסמו את כל תיקיית `accessibility-field-app` בכתובת HTTPS (למשל GitHub Pages או Cloudflare Pages בחינם).
2. פתחו את הכתובת בטלפון דרך Chrome באנדרואיד.
3. לחצו על `התקן בטלפון`, או פתחו את תפריט שלוש הנקודות ובחרו `הוספה למסך הבית` ואז `התקנה`.

קובץ שנפתח ישירות מהמחשב או מהטלפון ב-`file://` אינו יכול להפעיל Service Worker, ולכן אינו מותקן כ-PWA מלא. פעולות ביקורת וייצוא עובדות אופליין לאחר הטעינה; ניתוח AI דורש חיבור רשת ומפתח API של אותו סשן.

מגבלות ידועות מול ה-SRD:

- זו אינה אפליקציית Android Native.
- חיבור ה-AI הוא ישיר מהדפדפן, ולכן מתאים רק לשימוש אישי ומקומי. אין לפרסם את האתר עם פתרון זה, כי מפתח API לעולם לא צריך להיות חשוף למשתמשים אחרים.
- שימוש ב-OpenAI API הוא בתשלום לפי שימוש, נפרד ממנוי ChatGPT. שאר ה-MVP אינו דורש שירות או עלות חיצוניים.
- אין SQLite/Room: ב-PWA נעשה שימוש ב-IndexedDB המקומי של הדפדפן.
- אין סנכרון אוטומטי בין מכשירים. להעברה בין מכשירים משתמשים בייצוא גיבוי JSON ובייבואו במכשיר השני.

הקבצים נשמרו כך שאפשר להמשיך מהם למימוש Android מלא.
